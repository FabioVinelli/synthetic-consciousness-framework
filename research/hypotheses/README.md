# Research hypotheses — v0.1

Status: proposed, untested. No result is reported.

## H1 — primary hypothesis

**Under resource-matched conditions, adding explicit persistent self-modeling, epistemic monitoring, intentionality, consequence modeling, and reflective state revision produces measurable differences in agent performance compared with appropriate baselines.**

The primary causal comparison is C1 versus B1: the same underlying model, equivalent tools/context and resources, with versus without the Minimum Conscious Harness. B0 provides a base-model reference. See [methodology](../../docs/methodology.md).

### Operational prediction and null

Let Δ be C1 minus B1 in equal-case-weighted task-success rate, under the frozen evaluation distribution and budget. Let δ > 0 be a preregistered minimum meaningful difference.

- **H0 (statistical null):** Δ = 0.
- **H1 operational alternative:** Δ differs from zero; a practically meaningful difference requires magnitude at least δ.
- **Practical-equivalence region:** −δ < Δ < δ.

The original wording predicts differences, not their direction. A detrimental difference is not an improvement. Promotion requires a favorable primary effect plus the preregistered non-regression gates, including resource use.

### Falsification and interpretation

- A sufficiently precise equivalence analysis placing the prespecified equivalence interval entirely inside (−δ, δ) counts against the meaningful-difference prediction for the tested conditions.
- If a nominal benefit disappears in resource-matched comparisons, reject attributing that benefit to the harness mechanisms on that evidence.
- If preregistered ablations show equivalent performance with a mechanism removed, the necessity/contribution claim for that mechanism lacks support at the chosen resolution.
- A statistically non-significant, wide interval is inconclusive, not proof of H0 or falsification.
- A failure of controls, data integrity, or matching invalidates causal interpretation; it is not evidence for or against consciousness.

Predeclare the interval/equivalence method and thresholds before confirmation. Do not choose the most favorable metric after observing results.

## Mechanism hypotheses and ablations

| ID | Candidate contribution | Required ablation | Target family |
| --- | --- | --- | --- |
| H1-S | Persistent self-modeling changes capability-aware behavior | Remove persistent self-model; preserve context/storage budget | Reliability, goal adherence |
| H1-E | Epistemic monitoring changes support and uncertainty handling | Remove structured epistemic checks | Calibration, contradiction rate |
| H1-I | Explicit intentions change goal-linked action selection | Remove structured intentions; retain task objective | Goal adherence, tool selection |
| H1-C | Consequence modeling changes prospective action choices | Remove explicit consequence predictions | Tool selection, error recovery |
| H1-R | Reflective state revision changes verified corrections | Remove reflective revision; offer matched generic review | Metacognitive correction, adaptation |

These are proposed contributions, not established capabilities. Keep permission/safety gates constant in all ablations.
