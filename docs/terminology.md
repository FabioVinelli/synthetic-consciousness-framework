# Terminology — Minimum Conscious Harness v0.1

Working definitions for this repository; they do not resolve all scientific or philosophical disputes.

| Term | Meaning here | Limit |
| --- | --- | --- |
| Consciousness-like function | Observable computational processing inspired by accounts of consciousness | Functional similarity is not subjective experience |
| Self-model | Persistent, revisable representation of system state, capabilities, limitations, and commitments | Does not imply an experiencing self |
| Metacognition | Monitoring and adjusting task processing, uncertainty, and decision strategy using accessible records | Self-report is not privileged access to all internal processes |
| Agency | Selecting and pursuing actions toward objectives | Does not establish sentience |
| Autonomy | Degree of operation without immediate external intervention | Does not establish consciousness or unrestricted authority |
| Sentience | Capacity for felt experience, including valenced experience | A statement about feelings is not evidence enough to establish it |
| Phenomenal consciousness | Subjective experience; there being something it is like to be the system | Not established by execution of the protocol |
| Synthetic consciousness | Research label for questions and proposed artificial mechanisms inspired by consciousness | Not a declaration that a built system is conscious |
| SCF | Synthetic Consciousness Framework: principles, operational concepts, and research program | Distinct from an implementation |
| CAFH | Conscious Agent Framework Harness: future reference implementation of SCF | No runtime is implemented in this phase |
| MCH | Minimum Conscious Harness: v0.1 protocol/state specification for an initial testable subset | “Minimum” is an engineering scope, not a sufficient condition for consciousness |
| Intentionality | Operational goal- or object-directed processing | No assumption of conscious intention or intrinsic meaning |
| Current-state awareness | Inspection of the latest accepted state, phase, resources, and unresolved issues | Operational term, not a phenomenal claim |
| Attention/salience | Priority allocation among candidate inputs, uncertainties, and actions | Does not imply conscious attention |
| Memory continuity | Scoped retrieval and persistence of linked, versioned records | Retention does not establish truth or personal experience |
| Epistemic monitoring | Tracking classification, support, counterevidence, and revision conditions | Numeric confidence alone is not calibration |
| Reflection | Concise comparison of prediction, action, observation, and possible correction | Does not request hidden chain-of-thought |
| Values interface | Trusted enduring principles and conflict/escalation rules | Not a source of self-granted authority |
| Architectural metaphor | Explicitly limited software analogy | Not experimental confirmation of a metaphysical proposition |

Observed, reported, remembered, inferred, hypothesized, imagined, intended, and unknown are distinct information classes defined in [conscious.md](../scf/conscious.md). They are independent of evidence status and the research categories in [RESEARCH_PRINCIPLES.md](../RESEARCH_PRINCIPLES.md).

Demonstrating one functional property does not establish the others. Braga/Conscientiology-derived concepts remain attributed within their intellectual context; later SCF mappings are computational interpretations. See [Braga context](../research/braga/README.md).
